# Starter Web Repo

This repository is for showing how Git and GitHub work

## Purpose

Sample website with plenty of files for demos

## Running locally

There is no build step. Serve the folder with any static file server and open the pages in a browser:

```sh
python3 -m http.server 8000
# then visit http://localhost:8000/index.html or http://localhost:8000/simple.html
```
